Política de privacidad

Última actualización: 18 de octubre de 2026

Qué datos usa la app

Cuando conectas una cuenta (YouTube, Twitch, Kick o TikTok), MultiStream Control recibe un permiso de acceso de esa plataforma y lo usa únicamente para:

  • Leer y enviar mensajes del chat de tus transmisiones.
  • Leer y cambiar el título y la categoría de tus transmisiones.
  • Leer tu clave de transmisión para configurar el envío desde OBS.
  • Mostrar el nombre, la foto de tu canal y la cantidad de espectadores.

Dónde se guardan

Los permisos de acceso y las claves de transmisión se guardan sólo en tu computadora, cifrados con la protección de datos de Windows. La app se comunica directamente con las plataformas: no existe ningún servidor de MultiStream Control y no se envían tus datos a terceros.

Datos de YouTube

La app usa los Servicios de API de YouTube. Al usarla aceptas los Términos del Servicio de YouTube y se aplica la Política de Privacidad de Google. El uso de la información recibida de las API de Google cumple con la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo borrar tus datos

Pulsa "Desconectar" en la app para borrar el acceso guardado y revocarlo en la plataforma. También puedes quitar el acceso desde la configuración de seguridad de tu cuenta (por ejemplo, myaccount.google.com/permissions) o desinstalar la app.
